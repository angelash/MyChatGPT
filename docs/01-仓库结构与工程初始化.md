这份文档回答两件事：

1) **C# 工程和 Android 工程要不要你来创建？**
2) **推荐的仓库结构/工程结构是什么？**

---

## 0. 结论：工程“可以我来建”，但你必须做环境准备

### 0.1 C#（Windows）工程

- **建议我直接在仓库里创建**（目录结构、项目引用、基础配置一次到位）
- **你需要手动确保**：本机已安装 `.NET 8 SDK`（以及你习惯的 IDE：VS/VS Code/Cursor）

### 0.2 Android 工程

- **两种路线都行：**
  - **路线 A（推荐）**：我在仓库落一个标准 Gradle 工程骨架；你用 Android Studio 导入、Sync、运行
  - **路线 B**：你用 Android Studio 创建 “Empty Activity”，然后我按既定结构把代码补进去
- **你需要手动确保**：Android Studio + SDK 已安装（这部分无法在仓库里替你完成）

## 1. 推荐仓库目录结构（开工后会逐步出现）

```
/
  README.md
  design.md                       # 你现有的总体设计（保留）
  /docs                           # 执行准备/工程初始化/推进计划等
  /proto                          # 协议定义、schema、帧格式、测试向量说明
  /tests                          # 协议测试向量、离线音频测试数据说明
  /src
    /windows
      AudioBridge.sln
      /AudioBridge.Core           # 纯逻辑库：音频、抖动缓冲、codec、metrics
      /AudioBridge.Transport      # WS 协议、鉴权、二进制帧编解码
      /AudioBridge.Agent.Tray     # WinForms 托盘宿主：启停、设置、状态
    /android
      AudioBridgeClient           # Android Studio 工程根（Gradle）
```

## 2. Windows（C#）工程初始化建议（.NET 8）

### 2.1 建议的项目拆分（与 `design.md` 一致）

- `AudioBridge.Core`（Class Library）
- `AudioBridge.Transport`（Class Library）
- `AudioBridge.Agent.Tray`（WinForms exe）

### 2.2 建议依赖（先写“推荐”，真正落地以你确认的决策为准）

- **音频**：NAudio（WASAPI loopback / render / device 枚举）
- **WebSocket Server**：ASP.NET Core（Minimal API + `UseWebSockets`）
- **ADPCM（v1 默认省流）**：无需额外依赖（内置实现）
- **Opus（若选 Opus）**：Concentus（Windows 端）

> 如果你确认 v1 用 PCM16LE 或 ADPCM，那么 Opus 相关包可以先不引入，减少变量。

---

## 3. Android 工程初始化建议

### 3.1 语言与 UI

- Kotlin
- UI：默认先用 **XML（MVP 更稳）**；后续需要再换 Compose

### 3.2 建议依赖

- WebSocket：OkHttp
- 音频：AudioRecord / AudioTrack（系统 API）
- ADPCM（v1 默认省流）：无需额外依赖（内置实现）
- Opus（若选 Opus）：通常走 JNI + 预编译 libopus（MVP 不建议一上来就搞）

---

## 4. 需要你在本机确认/提供的信息（用于工程落地）

为了让工程结构和默认配置一次到位，请你确认：

- **包名（Android）**：建议 `com.audiobridge.client`（你可指定）
- **应用名**：建议 `AudioBridge`
- **Android 最低版本（minSdk）**：默认 21（尽量往低兼容）
- **Windows 监听端口**：默认 21347
- **是否只跑局域网**：默认是

---

## 5. 虚拟声卡推荐（你现在还没装的话）

推荐安装：**VB-Audio Virtual Cable（VB-CABLE）**。

设备名对照（非常关键）：

- 播放设备：`CABLE Input (VB-Audio Virtual Cable)` ← Windows 程序写入（注入“虚拟麦克风”）
- 录制设备：`CABLE Output (VB-Audio Virtual Cable)` ← 浏览器选择为麦克风
