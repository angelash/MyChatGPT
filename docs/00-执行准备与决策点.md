## 0. 目标与范围（MVP 口径）

**你要得到的最小可用闭环：**

- **下行（Windows → Android）**：Windows 抓系统声音（浏览器播什么就是什么）→ 通过网络发到手机 → 手机播放（建议戴耳机）
- **上行（Android → Windows）**：手机麦克风 → 通过网络发到 Windows → Windows 写入虚拟声卡 Playback → 浏览器选择对应的 Recording 作为麦克风
- **不做**：任何网页注入/抓 DOM、Realtime API 集成、视频传输、复杂 AEC（第一版默认戴耳机避免自激）

**验收的核心标准（个人使用版）：**

- **不断流**：连续 5 分钟通话不需要手工重连
- **能定位问题**：一键测试音/打开日志能判断是网络/设备/权限哪个环节出错
- **可接受延迟**：主观感受可用（不追求极致 <100ms；先保证稳定）

## 2. 你需要手动操作/安装/确认的事项（不可自动化）

### 2.1 Windows（必须）

- **安装虚拟声卡驱动**
  - 推荐：**VB-Audio Virtual Cable（VB-CABLE）**：最简单、最稳定、最贴合你当前“写入虚拟麦克风”的用法
  - 获取：官方站点（搜索关键字 `VB-Audio Virtual Cable`）
  - 安装：解压后以管理员运行 `VBCABLE_Setup_x64.exe`（或同名 Setup64），按提示安装，必要时重启
  - 安装后你应看到两条设备（名字容易混淆，按下面对照理解）：
    - **播放设备（Playback/Output Devices）**：`CABLE Input (VB-Audio Virtual Cable)` ← **Windows 程序要写入这个**（相当于“对虚拟线说话”）
    - **录制设备（Recording/Input Devices）**：`CABLE Output (VB-Audio Virtual Cable)` ← **浏览器/网页要选这个当麦克风**
  - 你这台机器上额外还出现了：`CABLE In 16ch (VB-Audio Virtual Cable)`（多通道端点）。**我们 v1 只用 `CABLE Input`/`CABLE Output` 即可**。
  - 建议把两端采样率都设为 **48kHz**（Windows 声音设置里可改），避免系统频繁重采样
- **确认设备链路**
  - 在 Windows“声音”里能看到虚拟声卡的 **Playback** 和 **Recording**
  - 你理解并确认链路：**Windows 写入 Playback → 浏览器选 Recording 当麦克风**
- **远程桌面（RDP）音频策略（强建议）**
  - 如果你用 RDP 只看画面：建议把“远程音频播放”设为 **在远程计算机播放**，避免默认设备被切到 `Remote Audio`
  - 无论如何：Windows 端程序将采用“**pinned 设备**”，不依赖默认设备（见 `design.md` RDP 章节）
- **放行防火墙入站端口**
  - 放行 `TCP <port>`（例如 21347），仅限局域网网段（建议）
- **准备一副耳机**
  - 第一版不做复杂 AEC，**不戴耳机非常容易啸叫/自激**

### 2.2 Android（必须）

- **安装 Android Studio（用于首次导入/调试/打包）**
- **权限**
  - 麦克风权限（录音）
  - 网络权限（默认就有）
  - （Android 13+）通知权限：用于前台服务常驻通知，保证退后台仍可持续语音
- **耳机**
  - 强烈建议使用有线耳机/蓝牙耳机，第一版会在 UI 做“未插耳机强提示”

### 2.3 网络（必须）

- **手机与 Windows 同一网络可达**
  - 同 Wi‑Fi 或手机热点
- **确认 Windows 的可达 IP**
  - 你需要提供/确认：Windows 在手机侧可访问的 IP（例如 `192.168.1.23`）

## 3. 开工前最小验证路径（建议 10–20 分钟完成）

> 这些验证能把 80% 的坑（设备/权限/路由/防火墙）提前暴露出来。

### 3.1 Windows 自检（不联网）

- **Loopback 抓系统声**：抓 10 秒输出到 wav，确认内容确实是系统正在播放的声音
- **写入虚拟声卡 Playback**：把一个 wav 播到虚拟声卡 Playback
- **验证虚拟麦克风**：在录音软件/浏览器里选择虚拟声卡 Recording，确认能录到刚才的声音

### 3.2 Android 自检（不联网）

- 录 10 秒本地 wav/pcm，回放确认清晰无爆音

### 3.3 联网自检（最小链路）

- 手机连上 Windows（WS hello/welcome + ping/pong），保持 5 分钟不断线
